# College-Attendance-System

### 1. Problem Statement

In colleges, maintaining student attendance manually takes time and effort. Teachers may find it difficult to manage student details and calculate attendance percentages.

Develop a College Attendance Management System using Python that allows teachers to:

- Add student details.
- View all students.
- Mark students as Present or Absent.
- View attendance records.
- Calculate attendance percentage.

### 7. Attendance Calculation

Attendance Percentage =

(Present Classes / Total Classes) × 100

Example:

- Total Classes: 10
- Present: 8
- Absent: 2
- Attendance Percentage: 80%

### 8. Conclusion

The College Attendance Management System is a beginner-level Python project that helps manage student attendance easily. It reduces manual work and helps teachers calculate attendance percentages using simple Python programming concepts.
